NullTrace is an educational OSINT tool. It only queries publicly reachable "is this email registered?" endpoints — it never emails the address, creates accounts, or attempts logins. Use it only on addresses you own or are explicitly authorized to test; you are responsible for complying with applicable laws and each site's terms of service.

Phone lookup validates and profiles a number offline (validity, country, line type, formatting). It does not check where a number is registered and never messages the number.
